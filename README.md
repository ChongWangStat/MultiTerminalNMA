# MultiTerminalNMA

Companion reproducibility materials for *Multi-terminal study resistances in network meta-analysis: correlated arms, two random-walk conjectures, and non-unique evidence routes* (Wang, Jin, O'Connor), prepared for *Research Synthesis Methods* (Research in Brief).

This repository is for **methodological reproducibility**, not clinical treatment-effect inference. The original psoriasis arm-level extraction is not redistributed while source permissions remain unresolved.

The verified source files and reproduction instructions are being added to this repository.
