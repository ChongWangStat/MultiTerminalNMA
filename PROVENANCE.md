# Data and code provenance

- Manuscript: Wang, Jin and O’Connor, *Multi-terminal study resistances in network meta-analysis: correlated arms, two random-walk conjectures, and non-unique evidence routes*, Research-in-Brief manuscript (2026).
- Original CSP implementation: Wang, Zhang, Jin and O’Connor, `https://github.com/ChongWangStat/CSP-NMA`, associated preprint arXiv:2604.21994; the existing CSP repository states an MIT license.
- Correlated-arm numerical examples: originally published by Rücker and Schwarzer (2025); the included Python code recomputes results from reported uncertainty entries.
- Psoriasis: Cochrane-derived arm-level input used in the CSP preprint. The file `pso-psa-data.csv` is excluded pending permission to redistribute the source extraction. Executable scripts and aggregate output checks are included.
- Structural simulation: authored simulation code frozen under seed 20261004, 18,000 analyses. It is a structural study and uses no restricted clinical data.
- Five-study network: historical illustrative construction related to CSP preprint; it is not a source-harmonized clinical NMA and should not be interpreted as one.
- Depression: numerical inputs based on Davies and collaborators' published dataset; follow citation and copyright in manuscript.
