# Reproduction guide

## Python environment

Use Python 3 and `python -m pip install -r requirements.txt`. Reported script checks were run locally on 12 Nov 2026. The historical R audits used R with `netmeta`, `meta`, `cccp` and `igraph`; the specific versions are reported in the paper's supplement.

## Core identities and examples

`brief/code/verify_math.py` and `brief/code/correlated_arm_examples.py` check the GLS multi-terminal calculations. `brief/code/route_audit_terminal.py` and `brief/code/route_bounds_terminal.py` evaluate the fixed five-study illustration, including the B:E route allocation bounds. Their input files are in `brief/figures/data/`; some scripts may assume the corresponding brief-project folder layout. The complete manuscript source package is available separately on request.

## Psoriasis data and analysis

The independent input `pso-psa-data.csv` was extracted from the Cochrane review cited in the manuscript and is not redistributed here. Obtain it via an authorized route and put it at `psoriasis/pso-psa-data.csv`. The scripts then use relative paths:

```bash
cd psoriasis
python psoriasis_route_audit.py --help
python run_psoriasis_native.py --help
```

`psoriasis_csp.py` specifies the preprocessing including the shared continuity correction and the within-study covariance. `run_psoriasis_csp.R` uses the originally released CSP implementation. The saved `psoriasis/verified_output/` summary is provided for verification even without the restricted input. The recovered November 2026 run obtained the two reported common/random-effect summaries and passed its route-bound checks.

## Structural simulation

The frozen simulation uses seed **20261004**. Reproduce the 18,000 analyses:

```bash
python simulation/simulation_structural_final.py --output-dir simulation/reproduced
```

Match `simulation/reproduced/structural_final_summary.csv` and `structural_final_main.csv` against `simulation/verified_output/`. The full 18,000-row file is generated by the script rather than committed as an input.

## Attribution and limitations

These are mathematical/software reproducibility materials. The five-study clinical-trial-inspired network is a fixed illustration and not a harmonized reanalysis of published randomized comparisons. The publication does not infer comparative clinical treatment effects from it. Source-specific rights and manuscript status are described in `PROVENANCE.md`.
